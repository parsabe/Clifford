# Clifford Windows source

Reserved development branch for Windows client source and compilation instructions. A native Windows
project/compiler target has not been implemented, and no EXE/MSI is available. The Linux kernel
includes POSIX filesystem protections and is not claimed to be a native Windows server build.

Windows users can currently connect a supported browser to the deployed HTTPS web client. Future
native client source will use the same kernel APIs and device microphone/speech facilities.
